Блоговая система на FastAPI с SQLite, аутентификацией, комментариями, избранным и подборками

видеообзор:
https://drive.google.com/drive/folders/1NSZd1o-4KPfpFtzO4DKfa3xDIqseggWq?usp=sharing

старт:
pip install -r requirements.txt
python app.py

Админ: admin
Возможности
Регистрация/логин/профиль
Посты (создать/редактировать/удалить)
Комментарии
Избранное
Персональные подборки
Поиск постов/пользователей
Пагинация, Markdown
Роли: admin/user
